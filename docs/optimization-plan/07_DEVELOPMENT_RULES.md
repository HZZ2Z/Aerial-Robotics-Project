# 开发规范与范围边界

## 工作原则

先保证场景真实，再检查统计，最后优化性能。每个性能结论都应能追溯到源代码提交、完整参数、随机种子、原始轨迹和指标定义。旧错误风场的更低RMS不能作为修复后退步的依据。

沿用MATLAB / Simulink、连续时间控制/估计、现有S-function和函数式目录。复用`quad_dynamics`、`euler_kin`、`run_closed`、`metrics`；不复制多份控制器/滤波器/指标公式。为9/12状态模式提取共享矩阵函数是必要的小改，新增通用框架不是本次任务。

## 代码与数值规范

1. 状态顺序、输入/输出维数、NED符号和单位写在函数头；Q可表示运动学也可表示噪声/代价矩阵，局部变量须明确命名避免混淆。
2. 所有真实环境参数和公开配置由params/场景构造入口提供；增益设计返回实际使用的矩阵，保存到run配置。
3. 随机流独立可复现，种子传入，不依赖全局rng遗留状态。S-function存储按实例维护，避免persistent mode索引造成跨实例污染。
4. 不在Derivative回调随机抽样。固定网格生成噪声，ODE子步重复读取同一段噪声；减小求解步长不得偷偷改变噪声实现。
5. 矩阵运算优先使用线性求解、Cholesky等；P需要对称性与半正定检查。不能用大幅截断负特征值掩盖传播错误；微小舍入处理需记录容差。
6. 同一run内所有日志时间对齐；离散状态边界使用明确左/右连续规则。不能跨fix边界平滑插值离散状态标签。
7. 原始命令、延迟后命令、实际施加输入分别记录。输出日志名称必须反映真实含义。
8. 指标采用时间加权定义，显示单位与窗口；比较实验只改变声明的因素。控制努力不是电能消耗，不能混称。
9. 任何数值结论先运行，再更新文档；生产报告不出现模板示例值。模板保留null和NOT_RUN，不填0冒充未测结果。
10. 只有课程明确给出的物理参数/限幅是硬要求。工程建议阈值执行前冻结，有理由的改变须记录并重跑相关比较，不能为隐藏失败临时放宽。

## 测试策略

优先保留并修复现有测试。新增测试应捕获已确认风险：实际风/日志不同、均值风未连接、τ错误、前馈符号、错误σ带、状态恢复、旧无效参数、指标√3差异、入口与场景覆盖。不要编写大量只复述赋值的测试。

先组件与短任务，再完整任务；复用同提交、同配置、同seed的有效运行。仅为剩余风险或阶段必需证据扩大测试。MATLAB不存在时，Python可以检查包、哈希和数学表达式，但不能作为Simulink执行的替代。

测试判定与任务进度分开：任务进度`NOT_STARTED / IN_PROGRESS / DONE`；执行判定`NOT_RUN / PASS / FAIL / BLOCKED / N/A`。`DONE`必须附该任务要求的证据；选做任务可`N/A`并说明。`RERUN PASS`只能来自实际完整复跑。

## Git 与产物管理

- 读取并遵守已有仓库/父目录AGENTS.md，本包不替换它。最新用户任务范围优先。
- 从实际基线创建本地工作分支，保留用户未提交更改；必要时使用隔离worktree。禁止强制reset/clean覆盖用户工作。
- 建议每阶段一个可审查提交；复杂P1/P2可拆成小提交。提交描述写清问题、改动、行为与实际验证。
- 不默认push、创建PR、评论、合并或发布；只有会话已有相应授权时执行。
- 输出写入按run分隔目录。包内不要包含缓存、绝对个人路径、旧指标冒充的新图、未许可课程材料。
- slx由构建脚本生成。二进制差异不等于连线差异；最终同时检查脚本和模型语义。

## 本次不做

不迁移到ROS/MuJoCo/Python作为课程主体；不引入MPC、RL、新GUI或云部署；不扩大为任意传感器插件平台；不添加新物理传感器来替代课程规定的AHRS/gyro/RTK基线；不以新的高级滤波器覆盖未完成的九状态要求。

不直接裁剪姿态状态来伪造35°满足；不读取真实风/真实位置给estimated路径；不选择性丢弃失败种子；不复制旧图并更换标题；不捏造作者、学号、执行时间或测试通过状态。

## 阻塞与继续执行

缺环境/许可证时继续所有独立的代码修改、静态核查与文档工作，交代可运行命令和明确依赖，相关动态项标BLOCKED。缺姓名学号不妨碍算法修复。只有影响任务实质取舍且无法从课程材料与本包解决的分歧，才向用户提出一个具体问题。

完成核心验收后停止追加调参。12状态与Bonus的价值用对照结果决定，收益不稳定可以保留为关闭的扩展，但报告应如实写明。
